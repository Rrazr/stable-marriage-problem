# Stable Marriage Problem Tool

## Description
The Stable Marriage Problem Tool is a C++ application designed for generating, analyzing, optimizing, and perturbing preference matrices for the Stable Marriage Problem (SMP). Through exhaustive backtracking, the application allows researchers to study the number of valid stable marriages (SM) that can arise from $n \times n$ preference matrices. 

The software includes capabilities for parsing standard and Latin matrices from files, brute-force benchmarking, targeted hill-climbing search optimizations (to find matrix variations that yield high quantities of stable matchings), and matrix reduction algorithms.

The tool directly contributed to the breakthrough findings outlined in the ["Improved Hill Climbing for the Stable Marriage Problem"](https://jstor.org/stable/community.39515645) poster presentation. This presentation placed first in the undergraduate Math & Computer Science category of [IFoRE 2024](https://www.sigmaxi.org/news/news-archive/2024/11/25/ifore-'24-student-research-award-winners).

## Prerequisites
To build and run this project, you need:
* A C++17 compatible compiler (e.g., MSVC on Windows, GCC, or Clang)
* [CMake](https://cmake.org/download/) (version 3.10 or higher)
* Git (optional, for cloning the repository)

## Install & Run

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Rrazr/stable-marriage-problem.git
   cd stable-marriage-problem
   ```

2. **Run the Automated Build Script**
   Execute the script that corresponds to your operating system to automatically run CMake, compile the C++ source code, and launch the executable.

   - **Windows (Command Prompt):** Double-click `build_and_run.bat` or run `build_and_run.bat` in your terminal.
   - **Windows (PowerShell):** Run `.\build_and_run.ps1` in your terminal.
   - **Mac/Linux:** Grant permission by running `chmod +x build_and_run.sh`, then execute `./build_and_run.sh`.

## File Management Note
**Important:** All input files (`.txt` files containing matrices) must be placed directly into the `inputs/` folder before running the program. Correspondingly, any files generated by the application will be automatically saved to the `outputs/` folder.

## Usage Guide (Options)

Upon launching the application, you will be prompted to enter the initial matrix size `n` (representing $n$ men and $n$ women). Once inside the main menu, you have several options available:

### `(G)` Generate and Calculate Random Samples
Prompts you for a number of samples. The system will randomly generate that many $n \times n$ preference matrices, calculate the number of stable matchings for each one, and generate a histogram showing the distribution of stable matching counts across your randomized batch. It also outputs the total execution time for performance profiling.

### `(C)` Calculate SM for Matrices
Allows you to feed the system a batch file containing a list of either **Standard matrices** or **Latin matrices**. 
- You will be prompted to provide an input file name (which must be placed in the `inputs/` folder) and an output file name. 
- The system evaluates every matrix, counts the stable matchings, and writes the evaluated matrix and its score directly to the `outputs/` folder.
- *Note:* Latin matrices are automatically converted into general standard form before being processed.

### `(H)` Hill Climbing Search
Applies a "hill-climbing" perturbation algorithm to systematically explore neighboring variations of a given matrix (by swapping two preferences at a time). The goal is to maximize the number of stable matchings. You can run this optimization on:
- **(A)** A newly generated random matrix.
- **(B)** A batch of Standard matrices imported from an input file.
- **(C)** A batch of Latin matrices imported from an input file.
The algorithm climbs to a "local maximum" and outputs the highest-yielding matrices to the `outputs/` directory.

### `(R)` Matrix Reduction
Given an input file populated with matrices of size $(n+1) \times (n+1)$, this option systematically reduces each matrix down to $n \times n$. It does this by systematically ignoring one row and one column, recalculating and normalizing the preference rankings to fit the smaller bounds, and then evaluating the stable matchings for the new, smaller matrix. Results are written to the `outputs/` folder.

### `(S)` Settings
A configuration menu where you can dynamically adjust global system constraints without restarting the application:
- **(1) Change matrix size (n):** Adjust the bounds of the SMP environment.

### `(Q)` Quit Program
Safely terminate the application.
